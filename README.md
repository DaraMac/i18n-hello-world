# i18n-hello-world
A Python Hello World program with internationalisation and localisation.
It provides one command `hello` that will print a localised "Hello, world" string when run in the terminal.

It should automatically change language based on user settings, or manually by setting the `LANGUAGE` environment variable before running.
This is meant to be an instructive project, both for the author and anyone else interested in producing multi-lingual Python tools.

See https://docs.python.org/3/library/i18n.html for an entry point into Python internationalisation.
